**TripMate | Travel Planner**

TripMate is a travel planning website designed to help users explore
destinations around the world, discover popular attractions, and plan
their next adventure.
Features
- Explore destination pages for Istanbul, Paris, Rome, Barcelona,
  Bangkok, Santorini, Bali, Hawaii, and Tokyo.
- Browse destination highlights and travel inspiration.
- Use the trip planner to select a destination and the number of days
  for a trip.
- Responsive, image-focused interface for exploring destinations.
Built With
- HTML
- CSS
- JavaScript
Getting Started
1. Download or clone this repository.
2. Open index.html in your web browser.
No build tools or package installation are required for the current
static website.
